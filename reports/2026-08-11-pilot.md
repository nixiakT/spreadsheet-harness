## Combined interpretation

Across the non-random 8-task pilot, end-to-end pass rate was **4/8 = 50.0%**. Six tasks completed and four passed, so completed-only accuracy was **4/6 = 66.7%**. Two tasks failed before any tool call because the Relay did not produce a first response within 180 seconds.

The server's current default `gpt-5.6-sol` was separately tried on one Cell-Level and one Sheet-Level prompt; both timed out before their first tool call. A minimal online check and the explicit visual smoke test did succeed with that configured provider. This points to prompt-dependent Relay/model latency, not a broken workbook or LibreOffice path.

The harness now retries transient Responses failures once by default and can be tuned with `--request-timeout` and `--request-retries`. Before a full 398-task run, use a stable provider/account pool, decide whether infrastructure errors count as failures, and preserve both end-to-end and completed-only metrics.

## Known comparison limits

- The published SpreadsheetBench evaluator only checks cached values and ignores formatting, merges, charts, macros, and most structural fidelity.
- Several official answer ranges contain malformed quoting or range syntax. The clean-room scorer repairs these and honors `answer_sheet`, so its numbers must be labeled as corrected-scorer results.
- The original benchmark protocol and some follow-up work differ on whether a solution is generated once and applied to multiple workbooks or the agent runs separately for each workbook. This pilot uses the latter.
- LibreOffice and Excel differ on modern functions, external links, dynamic arrays, and some formatting. Canonical Excel ranking requires an Excel-COM evaluation sidecar.
