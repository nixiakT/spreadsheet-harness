# Spreadsheet Harness 当前实验结果（2026-09-03）

## 一句话结论

目前已经完成可复核的 SpreadsheetBench-v2 30 题分层 pilot，并观察到
spreadsheet-harness 相对 bare code-only baseline 的明确增益；Financial 插件
在 pilot 中进一步多赢 1 题。完整 v1/v2（尤其 Visualization）尚未完成，
因此当前不能宣称公开榜单 SOTA。

## 1. 实验对象与协议

- 数据集：`KAKA22/SpreadsheetBench-v2`，固定 revision
  `9dea60025792fbac5928ce9f44812362dccbeecd`。
- v2 总规模：321 题：Template 97、Financial_Model 100、Debugging 100、
  Visualization 24。
- 当前主模型：LiteLLM 路由的 `qwen36-35b-a3b`（Qwen3.5-35B-A3B，
  thinking disabled 的开发/成本消融设置）。
- 评分：官方 evaluator；非 Visualization 任务要求 modification accuracy
  和 regression accuracy 同时为 1 才算整题通过。
- 五臂 pilot 合计约 7.04M tokens、702 次模型调用（各 arm 用量见结果
  `summary.json`）。
- 当前对照臂：
  - `bare`：仅代码工具的直接基线；
  - `spreadsheet-rl-minimal`：Spreadsheet-RL 风格的最小代码工具适配；
  - `paper-vision`：截图/视觉方法适配（当前 Linux 环境无法正常完成）；
  - `spreadsheet-harness-basic`：通用 Harness；
  - `spreadsheet-harness-financial`：Basic + Financial Modeling 插件。

## 4. 专项 Debugging 证据

在冻结的 5 个 held-out Debugging 任务上，使用 `policy-ours 1.23.0`：

- bare 平均 modification accuracy：0.14042；
- Harness 平均 modification accuracy：0.22876；
- 绝对增益：+0.08834；相对增益：+62.91%；
- 两边 regression accuracy 都是 1.0；5/5 配对审计有效。

报告：[`debugging_benchmark_evidence_20260825.md`](debugging_benchmark_evidence_20260825.md)。

这说明 Harness 的错误定位/修复策略对 Debugging 有明确帮助，但这是专项
冻结集证据，不等同于完整 v2 Debugging 榜单分数。

## 5. Harness 结构与论文叙事

- Basic 和 Financial 共享同一 runtime、profile、policy、通用插件、验证器
  和 repair；Financial 只额外加入 `skill-spreadsheet-financial-model`，可
  做干净的 domain-plugin ablation。
- 插件平面负责 capability/service 依赖、组合 hash、激活追踪和隔离；运行
  时由 policy planner + executor 调用代码工具，并用公式验证/回归检查闭环。
- 自进化机制已经实现候选插件的 replay、邻域迁移、回归验证、promotion/
  rollback 流程；Financial 领域数据和 held-out 协同进化实验尚未完成。

## 6. 与“公开强基线/SOTA”的关系

当前数值主要是同模型、同任务的内部 paired baseline（bare、Spreadsheet-RL
适配、视觉适配），用于证明 Harness 增益；它们不是公开论文模型的 SOTA 数值。
论文级 SOTA 比较应使用 SpreadsheetBench-v2 官方 leaderboard/paper 中的
公开模型，并匹配 thinking、50 interaction turns、模型和评测环境。当前
完整可比的 v1/v2 + Visualization 结果尚未跑完，因此汇报时建议表述为：

> “已完成 v2 分层 pilot 和专项冻结集验证，Harness 相对 bare 获得稳定增益；
> 完整 v1/v2 榜单复现及 SOTA 结论正在进行中。”
