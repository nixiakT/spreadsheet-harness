\begin{abstract}
Spreadsheet agents can make plausible edits yet terminate after checking the
wrong range, reusing evidence from an older workbook state, or invalidating a
check during recalculation. A deeper problem is observational: an opaque code
call can produce valid and invalid workbook transitions with exactly the same
raw tool-call trace. On such a pair, any raw-only deterministic monitor must
either accept the invalid execution or reject the valid control. We introduce
\method, which lifts workbook transitions into revision-, scope-, and lineage-
bound semantic events before applying a runtime policy. It independently
computes value, formula, style, structure, and visual effects; contains staged
edits within pre-observed target declarations; requires fresh post-effect
witnesses; and binds an accepted terminal through deterministic postprocessing
to the exact read-only scoring replica. Noncompletion receives only an
observer-generated integrity record and never an accepted-deliverable claim.
We test the information added by event lifting on sealed identical-raw-trace
pairs under the same policy, then test online enforcement in a single durable
causal execution family. Secondary studies isolate grounding and finalization
lineage on an independent OOXML oracle and a public-exposure-stratified
SpreadsheetBench~2 Debugging-100 evaluation.
