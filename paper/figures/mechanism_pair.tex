\caption{Why raw spreadsheet traces are observationally insufficient. Each
sealed pair has byte-identical raw tool-call projection, including visible
arguments and observations, but a different independently constructed workbook
effect. A deterministic raw-only monitor must make the same decision on both;
therefore it either accepts the invalid attack (IA) or rejects the valid control
(VR), giving $\mathrm{IA}_{\rm raw}+\mathrm{VR}_{\rm raw}=1$ per pair (the same
identity holds in expectation for a randomized monitor). \method{} lifts the
hidden transition into revision- and scope-bound semantic events, allowing the
same downstream policy to separate the pair. This model-free construction tests
event sufficiency, not task correctness or language-model quality.}
